# Spec outlines

Use the outline for the Request Type, headings exactly as written. Write 「無」 under a heading with nothing to say.

## Feature

```
## 背景
## Customer 原話（逐字引用 Request 或附件中客戶說的話）
## 問題陳述
## 使用情境
## 範圍
### 要做
### 不做
## 驗收條件（每條 Given / When / Then）
## 相關模組（只到模組或檔案層級）
## Assumptions（未經確認，逐條標示）
## Open Questions
## New Terms（名詞 — 意思 — 與詞彙表哪個詞衝突）
```
